# ⌨️ مرجع کامل دستورات و دکمه‌ها

## کاربران
| دستور/دکمه | کار |
|---|---|
| `/start` | ثبت‌نام + خوش‌آمد + بونوس لانچ (۱۰۰۰نفر اول) |
| `/help` | مرکز راهنما (۴بخش + FAQ) |
| `/cancel` | لغو عملیات جاری |
| 💗 با هرمسا گپ بزن | چت AI با حافظه |
| 🛒 فروشگاه | کاتالوگ، جستجو، خرید |
| ✅ کسب کردیت | تسک‌ها + 🎁 بونوس روزانه |
| 🏆 ماموریت‌ها | ۵ ماموریت + XP/سطح + جایزه |
| 🏆 لیدربورد | ۴ تب × این‌هفته/کل + مدال |
| 💰 کیف پول | واریز/برداشت/تاریخچه + 🎟 کد هدیه |
| 📦 فروش کن | ساخت محصول ۵قدمی + AI |
| 👥 دعوت دوستان | لینک + جعبه‌شانس + کمیسیون |
| 🎫 پشتیبانی | تیکت + گزارش تخلف |
| 📊 آمار من | خریدها، صدک، سطح |
| 💸 فروش من | درآمد، تبدیل، ستاره‌ها |
| `/mystats` `/mysales` | همان آمارها به‌صورت دستور |
