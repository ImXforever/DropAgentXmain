# استاد پرامپت 🎯
## اصول طلایی
1. **نقش بده:** «تو یک بازاریاب باتجربه هستی که…» — مدل با هویت بهتر جواب می‌دهد.
2. **زمینه بده:** محصول چیست؟ مخاطب کیست؟ لحن چه باشد؟
3. **فرمت بخواه:** «در قالب ۵ بولت»، «جدول مقایسه»، «حداکثر ۳ پاراگراف».
4. **مثال بده:** یک نمونه خوب نشان بده تا مدل الگو را بفهمد.
5. **تکرار کن:** مهم‌ترین قید را آخر پرامپت تکرار کن.

## قالب آمادهٔ فروش محصول
```
تو کپی‌رایتر فروش تلگرامی هستی.
محصول: [نام + توضیح یک‌خطی]
مخاطب: [مثلاً فریلنسرهای تازه‌کار]
بساز: ۱) سه عنوان جذاب ۲) توضیح ۱۵۰ کلمه‌ای با ایموجی ۳) سه بولت مزیت
لحن: صمیمی و پرانرژی. از وعدهٔ غیرواقعی استفاده نکن.
```
## خطاهای رایج
- پرامپت کلی → جواب کلی. هرچه دقیق‌تر، بهتر.
- چند کار در یک پرامپت → کیفیت افت می‌کند؛ قدم‌به‌قدم برو.
