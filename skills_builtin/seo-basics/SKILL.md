# سئو برای مارکت‌پلیس 🔍
## داخل DropAgentX
جستجوی بازار روی عنوان/توضیح است:
- عنوان: «[چی] برای [چه کسی] — [تفاوت]» → «پک پرامپت فریلنسر — ۲۰۰ عدد دسته‌بندی‌شده»
- توضیح: کلماتی که خریدار واقعاً تایپ می‌کند بنویس (پرامپت، قالب، آموزش…)
- دستهٔ درست انتخاب کن — فیلتر دسته مهم‌تر از عنوان است!

## بیرون بات (گوگل)
- صفحهٔ فروش تلگرامی اگر داری: عنوان H1 یکتا + پاراگراف اول حاوی عبارت اصلی
- اسکرین‌شات‌ها alt متنی داشته باشند
- لینک مستقیم بات با پارامتر — تا منبع فروش را بدانی
